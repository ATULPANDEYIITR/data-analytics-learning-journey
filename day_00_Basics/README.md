# data-analytics-learning-journey
My step-by-step journey learning data analytics, statistics, data visualization, and business intelligence.

This repository documents my progress as I learn data analytics from the fundamentals to practical analysis and business intelligence.

## Goal

To develop a strong foundation in data analytics by learning how to collect, clean, analyze, visualize, and communicate data to solve real-world problems.

## Learning Path

Data Analytics Fundamentals,

Excel,

Statistics,

SQL,

Python for Data Analysis,

Pandas,

Data Cleaning,

Data Visualization,

Power BI,

Business Intelligence,

Case Studies,

Practical Projects

# Day 00: Data Analytics Fundamentals

## Objective

Build a strong foundation in Data Analytics by understanding data, datasets, data quality, basic statistics, analysis, visualization, and the process of converting data into insights.

## Topics Covered

* Data Analytics
* Data and Datasets
* Variables
* Data Types
* Structured and Unstructured Data
* Data Collection
* Data Quality
* Missing Data
* Data Cleaning
* Descriptive Statistics
* Mean, Median, Minimum, Maximum and Range
* Data Grouping
* Percentage Change
* Correlation
* Data Visualization
* KPIs
* Types of Data Analytics
* Business Questions
* Analytics Workflow
* Analytics Tools
* Data Analyst Skills
